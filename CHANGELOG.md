# Changelog

All notable changes to `publishlayer/laravel-connector` will be documented in this file.

The format follows Keep a Changelog and the project uses Semantic Versioning.

## [0.1.0] - 2026-03-24

### Added

- First public release of the PublishLayer Laravel connector.
- Hosted knowledge base rendering with optional headless mode.
- Sync, health, webhook, activity, heartbeat, and inbox delivery flows.
- Install, health-check, heartbeat, diagnostics, webhook registration, and demo-seeding commands.
- Testbench-based package test suite and GitHub Actions compatibility matrix.

### Changed

- Tightened repository hygiene for Packagist and GitHub distribution.
- Expanded package metadata, publish tags, and release documentation.
- Standardized the hosted category route to `/categories/{slug}`.
- Documented the package around its actual public API, routes, and environment variables.
